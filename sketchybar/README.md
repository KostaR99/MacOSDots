# SketchyBar

Bottom, transparent 40px bar adapted from [`john-json/dotfiles`](https://github.com/john-json/dotfiles/tree/b90043e).

- Left: focused application
- Center: reversed AeroSpace workspace dots with an elongated active pill
- Right: clock, volume, Wi-Fi, media, weather, and CPU temperature

Requirements and linking instructions are in the repository [README](../README.md). Helper binaries are built automatically from the checked-in C sources when SketchyBar starts.
